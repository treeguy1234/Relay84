# TI-84 Plus CE Jailbreaking Guide

TI-84 Plus CE jailbreaking is essential for running any non-TI-BASIC programs on your calculator if the OS version is over *5.5.1*. All you have to do is download [Cesium Shell](https://www.ticalc.org/archives/files/fileinfo/465/46574.html) and [arTIfiCE Shell](https://yvantt.github.io/arTIfiCE/). Send them to your calculator via [TI Connect CE](https://education.ti.com/en/products/computer-software/ti-connect-ce-sw) or [WebTILP](https://tiplanet.org/scripts/webtilibs/webtilp.html). After that, run the program *A* from the program menu. Then, run the program *Cesium* to add cesium to your apps screen. To access Cesium, click **[apps]** then find the option *Cesium*. From there, you can run all of your favorite TI-84 Plus Programs.
